## 2. Java Project
* **Project Name:** Shopsphere
* **Description:**  ShopSphere - Advanced Java E-Commerce Management System


**ShopSphere** is a complete, enterprise-grade E-Commerce Management System developed as a capstone project. The application is built using a robust N-tier architecture to demonstrate core advanced Java functionalities, corporate web patterns, distributed systems, and desktop management systems within a single, cohesive workflow.

---

##  Key Modules
1. **Web Customer Application:** A responsive online storefront for users to browse products, manage their cart, apply coupons, and place mock orders.
2. **Swing Desktop Application:** A dedicated desktop management system built using Swing MVC architecture for administrative operations like inventory management and dashboard analytics.
3. **Distributed RMI Module:** A remote infrastructure system mimicking an automated network environment for inventory checks and lookups.
4. **Networking Module:** A lightweight `java.net` client-server implementation using sockets to execute low-level data transfers.

---

##  Technology Stack
* **Backend Core:** Java Enterprise Edition (J2EE Architecture)
* **Web Layer:** Jakarta Servlet (v6.1.0) & JSP (JavaServer Pages)
* **Presentation Components:** JSP Expression Language (EL), JSTL (Core & Functions), Custom Tag Files, and JSP Fragments
* **Frontend Design:** HTML5, CSS3, JavaScript, and Bootstrap 5
* **Desktop Client:** Java Swing (Pluggable Look and Feel Architecture)
* **Database & Persistence:** MySQL with Native JDBC API (`java.sql` using PreparedStatements for SQL injection prevention) [0.1.2, 3]
* **Distributed Services:** Java RMI (Remote Method Invocation) & RMI Registry
* **Networking Protocol:** TCP/IP Sockets via `java.net` (Socket & ServerSocket)
* **Build Automation:** Apache Maven
* **Deployment Web Container:** Apache Tomcat 11
